Desain dan Implementasi Autotuning PID menggunakan Fuzzy Logic Control pada Self-Balancing Robot

13 Juli 2026 Embedded Systems & Electronics Personal Project

Project Overview

Proyek ini berfokus pada perancangan dan implementasi robot penyeimbang otomatis (self-balancing robot) menggunakan metode autotuning PID berbasis Fuzzy Logic. Sistem ini dirancang untuk meningkatkan kestabilan robot dengan menyesuaikan parameter PID (Kp, Ki, dan Kd) secara otomatis berdasarkan nilai error dan perubahan error sudut kemiringan robot.

Menggunakan mikrokontroler ESP32 dan sensor MPU6050 untuk membaca orientasi robot secara real-time. Metode Fuzzy Logic digunakan untuk menentukan penyesuaian parameter PID agar robot mampu mempertahankan keseimbangan, termasuk saat beroperasi pada lintasan miring.

Key Highlights

  • Pengukuran sudut kemiringan secara real-time menggunakan MPU6050.
  • Penyesuaian parameter PID otomatis menggunakan Fuzzy Logic.
  • Sistem kendali tertanam berbasis ESP32.
  • Pengendalian motor DC untuk menjaga keseimbangan robot.
  • Dapat bertahan hingga 15° dari sudut acuan

System Workflow

1. Sensor Acquisition

Sensor MPU6050 membaca data akselerometer dan giroskop untuk memperoleh informasi orientasi serta pergerakan robot.

2. Data Processing

ESP32 memproses data sensor untuk memperoleh sudut kemiringan robot sebagai dasar perhitungan sistem kendali.

3. Fuzzy Logic Controller

Nilai error dan delta error menjadi masukan sistem Fuzzy Logic. Proses fuzzifikasi, evaluasi aturan, dan defuzzifikasi digunakan untuk menentukan parameter PID.

4. PID Control

Parameter Kp, Ki, dan Kd digunakan dalam perhitungan kendali untuk menghasilkan respons koreksi berdasarkan kondisi robot.

5. Motor Actuation

Sinyal kendali diteruskan melalui driver L298N untuk mengatur arah dan kecepatan motor DC.

6. Feedback Control

Sensor kembali membaca perubahan orientasi robot sehingga sistem dapat melakukan koreksi secara berkelanjutan.

Project Objective

Pengembangan proyek ini ditujukan untuk memahami dan mengimplementasikan sistem kendali adaptif pada robot bergerak, khususnya melalui integrasi sensor, mikrokontroler, algoritma PID, dan Fuzzy Logic.

Selain itu, proyek ini menjadi penerapan praktis konsep sistem kendali, elektronika, dan embedded systems dalam membangun perangkat robotika yang mampu mempertahankan keseimbangan secara otomatis.
